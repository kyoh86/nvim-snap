# Regression snapshot handling

Regression cases detect changes by comparing saved snapshots across commits or other ids.

For regression cases, you must save the execution results as snapshots.
nvim-snap stores them under:

`<root>/<cases-dir>/.result/regression/<case-name>/snapshot-<id>.json`

## CI

As in the `nvim-snap.yml` generated by `nvim-snap init`, using
[`actions/cache`](https://github.com/actions/cache) is recommended.

```yaml
- uses: actions/cache@v4
  with:
    path: snapcase-example/snapcase/.result
    key: nvim-snap-${{ runner.os }}-${{ github.sha }}
    restore-keys: |
      nvim-snap-${{ runner.os }}-
```

## Local

Snapshots should be treated as temporary files and not committed.
They can grow quickly, and storing them in a plugin repo can slow installs.
`nvim-snap init` generates a `.gitignore`, and you should keep the results ignored.

Example:

```console
$ git switch base-branch
$ nvim-snap regression save
diff-example    ok
layout-splits   ok

$ git switch feature-branch
$ nvim-snap regression save
diff-example    ok
layout-splits   ok

$ nvim-snap regression test --base $(git show --format='%H' --no-patch base-branch) --target $(git show --format='%H' --no-patch feature-branch)
```
